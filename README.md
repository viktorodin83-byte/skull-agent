# Telegram-бот "Универсальный помощник"

Telegram-бот на `python-telegram-bot`, который:

- отвечает на вопросы, ищет информацию в интернете (DuckDuckGo, резерв — Google Custom Search) и формулирует ответ через Claude API;
- принимает и озвучивает голосовые сообщения (OpenAI Whisper/TTS);
- ищет и присылает картинки по запросу;
- ищет цены товаров на Ozon и Avito (Apify), не путая их с ценами на биржевые активы (золото, валюту, крипту и т.п.);
- редактирует изображения по текстовой инструкции;
- отдельная независимая нода: раз в час анализирует технический сигнал по золоту (XAU/USD — RSI, MA, уровни Фибоначчи, пробитие канала) и присылает его в чат, самообучаясь на точности прошлых сигналов. На каждый реальный сигнал дополнительно спрашивает Claude (с доступом к веб-поиску) — не противоречит ли текущий новостной/макро фон технической картине.

## Установка

```bash
pip install -r requirements.txt
cp .env.example .env
```

Заполни `.env` своими ключами (см. комментарии в `.env.example`). Файл `.env` не коммитится — он в `.gitignore`.

## Запуск

```bash
python bot.py
```

На Windows есть вспомогательные скрипты:

- `start_bot.bat` — запуск с окном консоли (видно логи, для отладки).
- `start_bot_silent.bat` — фоновый запуск без окна.
- `watchdog.py` — сторож: следит за логом бота, перезапускает его, если тот завис (актуально после выхода компьютера из сна/гибернации). Можно добавить `start_telegram_bot.bat` (запускает `watchdog.py`) в папку автозагрузки Windows.

## SkullByte — агент глубокого анализа XAU/USD

`skullbyte.py` — полностью отдельный бот (свой токен `SKULLBYTE_TOKEN`, свой процесс),
не связан с основным ботом. Работает по запросу, без расписания: пользователь пишет
что угодно (или `/gold`) — в ответ приходит разбор, объединяющий:

- технический сигнал на часовом и дневном графике XAU/USD (Twelve Data);
- реальную доходность 10-летних облигаций США (FRED, ряд DFII10);
- текущие цены золота и серебра и их соотношение (UniRateAPI, нужен Pro-тариф);
- синтез от Claude с доступом к веб-поиску (новостной/макро фон, риски).

```bash
python skullbyte.py
```

## Структура

- `bot.py` — основной бот, все обработчики сообщений.
- `analysis.py` — технический анализ XAU/USD (используется и нодой сигнала в bot.py, и skullbyte.py).
- `skullbyte.py` — отдельный агент глубокого анализа XAU/USD по запросу.
- `watchdog.py` — сторож для автоперезапуска после сна/зависания.
- `requirements.txt` — зависимости.
- `.env.example` — список нужных переменных окружения (без значений).
